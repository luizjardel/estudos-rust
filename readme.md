# Estudos Rust 🦀

*[Read in English below](#rust-studies-)*

Repositório com exercícios e anotações dos meus estudos da linguagem **Rust**.

## Sobre

Este repositório reúne pequenos projetos e exercícios feitos durante o aprendizado de Rust, cobrindo desde conceitos básicos até tópicos um pouco mais avançados, conforme o progresso.

## Como rodar os projetos

Cada pasta é um projeto Cargo independente. Para rodar qualquer um deles:

```bash
cd nome-da-pasta
cargo run
```

## Exercícios

| Pasta | Tema | Descrição |
|-------|------|-----------|
| `Calculadora-Area` | Variáveis e tipos | Calcula a área de um triângulo a partir de base e altura |
| `variaveis` | Variáveis e mutabilidade | Demonstra a diferença entre variáveis imutáveis e mutáveis (`mut`) |
| `mut-pontos` | Mutabilidade | Simula um contador de pontos de jogo, somando e subtraindo valores |
| `if-else` | Condicionais | Verifica faixas de temperatura usando `if`, `else if` e `else` |
| `loops` | Loops | Percorre números de 1 a 10 com `for` e verifica se são pares ou ímpares |

# Rust Studies 🦀

*[Leia em português acima](#estudos-rust-)*

Repository with exercises and notes from my **Rust** language studies.

## About

This repository gathers small projects and exercises made while learning Rust, covering basic concepts up to slightly more advanced topics, as progress continues.

## How to run the projects

Each folder is an independent Cargo project. To run any of them:

```bash
cd folder-name
cargo run
```

## Exercises

| Folder | Topic | Description |
|--------|-------|-------------|
| `Calculadora-Area` | Variables and types | Calculates a triangle's area from base and height |
| `variaveis` | Variables and mutability | Demonstrates the difference between immutable and mutable (`mut`) variables |
| `mut-pontos` | Mutability | Simulates a game score counter, adding and subtracting values |
| `if-else` | Conditionals | Checks temperature ranges using `if`, `else if`, and `else` |
| `loops` | Loops | Iterates through numbers 1 to 10 with `for`, checking even/odd |
